# Noorix Chatbot

Noorix is an AI-powered chatbot web application that allows users to interact via text and file uploads. It supports dynamic responses, file attachments, and a smooth chat interface with a typing effect.

## Features

- Conversational AI chatbot interface
- Supports text input and file attachments (images & documents)
- Smooth typing effect for bot responses
- Retry mechanism for API calls
- Stop bot responses mid-generation
- Delete chat history
- Dark and Light theme toggle
- Suggestion buttons for quick prompts
